\# Phase 1: Cybersecurity Tools



A collection of small cybersecurity and automation tools built for Phase 1.



\## Tools

\- \*\*Bash Tool\*\* — planned; details will be added when it’s complete.

\- `Bash-Tool/` — Bash project files and screenshots, to be added.
